# Nightscout MongoDB

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Runs the official [MongoDB][mongo] 7.0 image as storage for the **Nightscout**
add-on. It is reachable from the add-on network only and publishes no host
ports.

See the [documentation](DOCS.md) for setup and options.
